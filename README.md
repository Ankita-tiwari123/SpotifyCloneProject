🎵 Spotify Clone (Web Music Player)

A Spotify-inspired web music player built using HTML, CSS, and JavaScript.
This project demonstrates core frontend concepts such as UI design, event handling, and audio playback using the HTML5 Audio API.

📌 Features

🎶 Play / Pause music

⏭ Next & ⏮ Previous song controls

📊 Interactive progress bar

🎧 Song selection from playlist

🌙 Spotify-style dark theme UI

📱 Clean and responsive layout

🛠️ Technologies Used

HTML5 – Structure of the web application

CSS3 – Styling and dark theme design

JavaScript (ES6) – Music logic & interactivity

Font Awesome – Icons

HTML5 Audio API – Audio playback

▶️ How to Run the Project

Download or clone the repository

git clone https://github.com/Ankita-tiwari123/spotify-clone.git


Open the folder in VS Code

Make sure the songs folder contains .mp3 files

Open index.html in your browser
(or use Live Server extension)

🧠 How It Works

JavaScript controls audio playback using the Audio() object

Event listeners handle play, pause, next, and previous actions

Progress bar updates dynamically with song duration

UI icons toggle based on song state
